# ☕ Primeiros Passos em Java SE

Este repositório é o registro da minha jornada de consolidação na linguagem Java. O foco aqui é o domínio da **lógica pura** e sintaxe, desenvolvendo algoritmos "na mão" utilizando apenas **Sublime Text** e **Terminal**.

Agradeço ao professor **Arnaldo Souza** (Udemy) pela excelente didática que tem guiado esses passos iniciais.

## 🛠️ Projetos no Repositório

### 1. Sistema de Checkout de Mercado 🛒
Simulador de PDV focado em cálculos e fluxos de repetição.
- **Conceitos:** Loops (`while`), acumuladores e condicionais.
- **Regra de Negócio:** Aplicação automática de 10% de desconto para compras acima de R$ 100.

### 2. Simulador de Caixa Eletrônico (ATM) 🏦
Aplicação interativa que gerencia o estado de um saldo bancário em tempo real.
- **Conceitos:** Menu interativo com `switch-case`, persistência de dados em variáveis e tratamento de estados.
- **Regra de Negócio:** Validação de saldo insuficiente e bloqueio de entradas negativas.

### 3. Validador de Acesso e Segurança 🛡️
Módulo de login focado em manipulação de textos e segurança de fluxo.
- **Conceitos:** Comparação de Strings (`.equals()`), contadores de tentativas e flags booleanas.
- **Regra de Negócio:** Sistema de segurança que bloqueia o acesso após 3 tentativas incorretas (Anti-Brute Force).
